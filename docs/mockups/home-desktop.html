Three sources

Separate observations. One correlatable record.

Each source has its own key, scope and view of the incident. None of them is treated as a complete account on its own.

Provider host

An unprivileged Linux agent records host heartbeats, GPU telemetry availability, UPS transitions and agent status with fixed collectors.

  • Bounded, typed event payloads
  • Durable local spool and retry
  • No remote shell or arbitrary commands

HOST-SIGNED · ED25519

Renter workload client

An incident-scoped SDK runs in the renter's workload and records workload heartbeats plus endpoint reachability results.

  • One-use invitation enrollment
  • Incident-scoped signing key
  • Explicit unreachable and gap states

RENTER-SIGNED · SCOPED KEY

Platform-operated probe

A separate worker checks the verified public endpoint with a fixed HTTPS GET. It is platform-operated, not an independent third party.

  • DNS-verified public hostname only
  • Pinned address, no redirects or proxies
  • Bounded result categories and latency

PLATFORM-OPERATED · NOT INDEPENDENT

Offline verification

Check the bundle without trusting the server.

A sealed bundle contains the manifest, source certificates and signed observations. The local verifier recomputes digests and checks every signature in the browser.

  • Canonical manifest digest and platform signature
  • Source certificates, key scope and event signatures
  • Deterministic order, sequence and capture-window bounds
  • Explicit simulation labels and evidence gaps

Signature verification confirms integrity and provenance from a key. It does not prove sensor truth or root cause.

What the evidence can and cannot do

Useful for reconstructing a timeline. Not an outage verdict.

It can help support

A source-attributed sequence of observations, a deterministic evidence pattern and tamper detection against the sealed bundle.

It cannot establish

Sensor truth, physical root cause, fault or intent, or whether a marketplace should excuse downtime or change a reliability score.

The platform probe is platform-operated, not an independent third party. Missing UPS, GPU, renter or probe observations are represented as gaps or unavailable data — never as normal.
