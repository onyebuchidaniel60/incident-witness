Treatment rules

Always explicit

Status uses text plus colour. Unknown, unavailable and stale states are not rendered as green or as a healthy default.

Always actionable

Errors provide a retry or a safe next step. Restricted records return a not-found treatment without revealing another account's resource.

Static Phase 6 state treatments. Controls are illustrative and not connected to the application. Final state implementation belongs to Phase 7 after explicit mockup approval.
