# Satoshi font attribution

The Phase 6 mockups bundle three WOFF2 files of **Satoshi**:

- `Satoshi-Regular.woff2`
- `Satoshi-Medium.woff2`
- `Satoshi-Bold.woff2`

**Designer/foundry:** Indian Type Foundry (ITF), distributed via Fontshare.

**Source:** https://www.fontshare.com/fonts/satoshi

**License:** ITF Free Font License (FFL), as published by Fontshare: https://www.fontshare.com/licenses/itf-ffl

The files are used only for the static Phase 6 design mockups under `docs/mockups/`. They are not imported by `apps/web`. Production font loading, self-hosting and licensing confirmation remain a Phase 7 implementation decision.

If the license terms change or the operator prefers a different geometric sans, replace these files and update the `@font-face` declarations in `docs/mockups/assets/mockup.css`.
